# Craft Spend 💳

A fast, offline-first personal expense tracking Progressive Web App (PWA) designed for frictionless daily logging and Kigali RWF budgeting.

## Features
- **Offline-First PWA**: Runs anywhere, anytime with full Service Worker caching.
- **RWF Quick Increments**: Fast `+1,000`, `+2,000`, `+5,000`, `+10,000` buttons.
- **Expense Categorization**: Groceries, Dining Out, Transport, Utilities, Fun, Shopping, Health, Other.
- **Monthly Burn Rate & Analytics**: Live progress bar, remaining daily allowance, and visual breakdown.
- **Cloud Sync Support**: Real-time Supabase REST sync connector to ensure zero data loss across devices.
